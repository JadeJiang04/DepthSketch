# 光照与场景融合的后续方案

当前只实现边缘羽化，尚未实现下述光照。这些是工程方案，不是已验证的效果或性能结论。

## 与原项目对照

早期场景原型不放光源，使用 `MeshBasicMaterial` 保持原图纹理；长边最多 240 个顶点，每个网格格子始终保留两个三角形。Android 版此前加入的深度差删面造成正视角漏底，0.3.2 已恢复连续网格。

原图已经包含拍摄或绘制时的光照。直接再套强烈的三维漫反射容易叠加阴影，并破坏二次元角色的脸部。因此保留“原图”作为默认和可随时切回的对照。

## 第一阶段：亮度、色温与接触感

建议先实现只作用于抠图对象的曝光、色温、饱和度及融合强度。自动初值从放置位置附近的背景估计，排除极亮灯珠与纯黑区域，并限制修正幅度；自动建议允许手动覆盖。附近照片的颜色同时受材质影响，不能当作准确的环境光测量。

在角色片段着色器内先将 RGB 转为线性空间，再施加增益与色偏，输出时恢复显示编码。保留 alpha、深度测试、原始纹理和现有 SDF 边缘羽化；参数为 uniform，调节时不重新运行深度或分割网络。每个对象分别保存参数，默认强度为零。

站立道路的第一例可增加可调的柔和接触阴影，让脚贴地。它是近似效果，不自动套到只露上半身或柱后的人物，避免在错误表面画阴影。光源方向、阴影长度和透明度需要用户能修正。

## 第二阶段：可选的方向光

从抠图深度生成平滑、低频的近似法线，并与正面法线混合。透明轮廓两侧不互相取样；法线只在创建对象时生成并缓存。用户可以点选路灯作为近似光源，或直接调整方向、颜色和强度。

相对深度没有可靠的物理尺度，不能把它生成的法线解释为真实人体几何。人物的 XYZ 旋转和非均匀缩放需要用正确的法线变换；默认小强度，防止把平面角色照成凹凸石膏。

## 后续可选：一次性重打光

[IC-Light 官方实现](https://github.com/lllyasviel/IC-Light)提供以文字或背景为条件、以前景图为输入的重打光模型。可以作为更强的一次性素材处理候选，但本项目尚未验证它的角色细节保持、手机内存或耗时，不把它接入实时壁纸循环。

## 验证方式

用现有三张夜景和两张角色，在相同位置、尺寸、相机及深度下对照“原图 / 仅曝光色温 / 加接触阴影 / 可选方向光”。优先检查脸部肤色、白发高光、衣服色彩和边缘；不得通过更换背景或生成不同人物来掩盖问题。比较静止与倾斜视角，确认草丛和柱子的遮挡、编辑响应及壁纸静止停绘均保持正常。
