# DepthSketch：轻量化、可编辑的 3D 壁纸

[English](../../README.md) · [下载 Android APK](https://github.com/JadeJiang04/DepthSketch/releases/latest)

把普通图片变成有深度的场景，再从其他图片中抠出对象进行拼贴，也可以直接导入准备好的透明素材、自由绘制 3D 笔画。通过位置、深度与 XYZ 旋转安排前景和背景，让对象形成前后遮挡，最后设为随手机倾斜产生视差的动态壁纸。

项目面向通用照片与图案，不限定动漫或任何一种主体。重点是可以亲手编辑、调整的布景体验。

## 下载安装

在 [Releases](https://github.com/JadeJiang04/DepthSketch/releases/latest) 下载 `DepthSketch-0.3.3-android.apk`，支持 Android 8.0 及以上。当前提供实验体验版，界面为中文。

APK 内置全部模型，约 **216 MiB**，首次使用不需要下载模型。“轻量化”指采用小模型和原生缓存渲染，不代表安装包很小。现有安装可以尝试直接覆盖更新；自编译版本的签名若不同，则不能直接覆盖体验版。

## 基本流程

1. 点击“＋ 图片”导入背景，Depth Anything V2 Small 在手机本地估计深度，将图片转换为带纹理的 2.5D 场景。
2. 在“⋯ → 从新图片点选抠图”选择另一张图片，通过“选主体”添加前景点、“排除背景”添加负点。确认轮廓并加入时，对图片估深，将对象图像与对应深度一起裁出。
3. 已经准备好的素材从“⋯ → 直接导入图片素材”加入，跳过分割。透明图片保留原始透明度、半透明边缘与分离的小部件；不透明图片整张按矩形导入，不自动去背景。两种输入都会估计深度。
4. 拖动对象调整位置，在悬浮编辑框中调整大小、前后深度、表面起伏及 XYZ 旋转；边缘柔化可帮助简单融合。对象之间与背景通过深度测试形成遮挡。
5. “贴面”沿照片表面绘画，“悬空”在统一深度平面绘画。一次按下到抬起是一笔独立对象，之后可以选择、旋转、复制、删除、撤回和重做。
6. 双指移动和缩放画布，“视角”模式单指环绕；“正视”恢复默认观察角度。悬浮编辑框可拖动、折叠或关闭。
7. 菜单选择“预览重力动态壁纸”，调整完整适配或填满裁切，再进入系统确认。壁纸读取独立场景快照，后续修改作品需要重新预览并确认。
8. 可导出 PNG 或保存 `.dsketch` 可编辑项目。自动保存只保留当前画布，替换照片前请导出需要留存的作品。

“合成重估”是独立实验入口：将照片、拼贴对象和笔画按正视角合成，再估计整幅图的深度，打开新预览并保留原分层作品。重估结果是一张图，不能继续单独选中其中的原始对象，效果也不保证一定更好。

## 0 API，端侧运行

核心流程没有推理 API 调用，不需要密钥、账号、华为服务或云端推理，应用没有联网权限。深度估计与 MobileSAM 分割通过 ONNX Runtime 在 CPU 本地执行。

模型用于图片准备阶段；绘制、编辑和壁纸播放复用深度和 GPU 几何，不会每次操作重新估深。壁纸不可见时停止绘制并注销传感器。采用小模型与缓存来降低重复编辑开销，但不承诺所有手机都能实时推理，准备耗时与设备和图片有关。

## 导出后使用大模型精修

可将导出的 PNG 交给外部多模态或图像编辑大模型，作为构图参考，进一步统一光照、色彩、边缘和细节。这是可选的后处理流程，当前应用没有接入大模型 API。外部服务的费用和隐私规则单独适用。

精修后的平面图不会保留原来的可编辑图层；可以重新导入并估深。建议同时保存原始 `.dsketch` 项目。

## 技术与边界

- 原生 Android Java、OpenGL ES 2.0、ONNX Runtime；支持 ARM64、ARMv7、x86_64。
- Depth Anything V2 Small 估计相对深度，MobileSAM 提供点选分割。
- 当前深度工作分辨率为短边目标 280、长边上限 504，并对齐到 14 的倍数；源图长边最多 1536 像素，网格长边最多 240 个顶点。
- 单图提供可见表面的 2.5D 结构，没有完整侧面、背面和被遮挡背景；大幅旋转可能拉伸或露出空缺。
- 深度不是米制距离；分割质量依赖输入和提示点。自动重光照与隐藏背景补全尚未实现。
